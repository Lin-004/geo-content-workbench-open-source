# 产品说明

工作台管理内容规划、独立内容资产、审核和人工发布确认。当前为单人工作台审核模式，所有登录账号具有相同工作台权限，没有团队角色与分级审批。

## 数据关系

一个项目按上海自然日维护每日规划，同一项目同一天只有一条每日规划。每日规划包含多条文章规划项；规划项与正文资产分开保存。支持 A/B/C 等内置分类、开放分类编码和同类多篇，不限定每天三篇。

每条有效规划项最多关联一条有效内容资产。每篇内容按目标平台产生独立发布任务，不在文章之间共享任务。文章和短视频文字脚本都属于内容资产；脚本审核通过不表示视频成片已经发布。

## 内容与审核

内容从 `draft` 提交到 `reviewing`，审核通过为 `approved`，驳回回到草稿。审核中不能编辑。已审核、尚无发布结果的内容修改标题或正文会退回草稿；已有平台发布结果的母稿只读，通过复制修订稿修改。

提交审核需要有效正文；导入内容缺少完整正文时可保存草稿骨架。审核记录保存正文、图片和平台快照。软删除进入回收站，恢复时检查规划项占用冲突。

正文支持富文本、表格、图片、Markdown 与预览。Markdown 无法完整表达合并单元格；PDF 导入只提取文字，不承诺保留原排版。

## 规划导入

项目详情提供 XLSX v2 模板，含项目 ID 和名称，兼容 v1、Markdown 与 DOCX。规划导入只创建每日规划和规划项，不创建正文资产或发布任务。

按项目、日期与稳定 `itemKey` 匹配规划项。相同记录为无变化；当前或未来未关联内容的项可更新；历史日期或已关联内容的变更跳过。未在文件中出现的项保持原样。

同一天每日主题或非空每日备注冲突时跳过当天；重复 itemKey 的所有重复行都跳过。单行错误不阻止其他有效项；项目、模板及文件级错误阻止整批。

预览只读，返回绑定用户、项目和有效期的签名凭证。确认只接受项目与凭证，重新计算差异并在事务中保存有效项和跳过清单；运行故障回滚本次事务。

## 发布与进度

审核通过后，平台任务由 `blocked` 变成 `pending`。用户到平台人工发布，再登记真实 URL，任务变为 `published`。确认一个平台不影响其他平台。

每日规划状态由有效规划项、内容审核状态和发布任务聚合：未创建、创建中、待审核、待发布、发布中、已完成。未创建全部规划文章时不能显示全部完成。

## 页面与接口

| 页面 | 路由 |
| --- | --- |
| 工作看板 | `/dashboard` |
| 内容排期 | `/content-schedule` |
| 项目管理 | `/planning-management` |
| 内容资产 | `/content-management` |
| 发布任务 | `/publications` |
| 设置 | `/settings` |
| 帮助 | `/help` |

项目详情的“查看全部规划”在当前项目内展开，不跳转到其他项目。内容排期按项目与日期聚合，筛选条件保存在 URL。

规划导入接口为 `GET /api/import/plans/template`、`POST /api/import/plans/preview` 和 `POST /api/import/plans/confirm`。内容导入接口为 `POST /api/import/content/preview` 和 `POST /api/import/content/confirm`。全部业务操作需要认证；完整参数见 [Agent API 契约](../agent-skills/geo-workbench/references/api-contract.md)。
