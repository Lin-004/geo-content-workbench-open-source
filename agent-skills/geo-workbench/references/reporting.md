# 进度复盘

`WB report --project 1 --from 2026-10-08 --to 2026-10-14`。

分页读取项目和日期范围内每日规划、规划项、有效资产及平台任务。资产范围包括关联规划资产、旧 contentAsset 关系、无规划且 plannedPublishDate 落在范围的项目资产。无规划无日期不计本期；删除资产的任务排除。任务完成率与文章完成数分开。

规划 status 只聚合已有资产，done 仍可能缺规划项文章，必须额外检查 coverage。按分类+问题完全一致匹配：零候选 unmatched（可能未创建或元数据缺失）；多个候选/多个规划项占用同一资产 ambiguous。没有唯一关系，不能宣称是权威缺失判断。读取旧关系时去重，不模糊匹配。

查询不是事务快照；并发编辑可能有暂时差异。脚本分页异常会失败，不能把截断数据报成完整结果。与页面统计不同时先说明范围、过滤和数量上限差异。

按日期/文章/平台列出下一动作和详情链接，说明 unmatched/ambiguous 不确定性。不将交付完成率当作 GEO 效果、AI 引用率、排名或曝光提升。
